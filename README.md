# Setup Forge HQ

Build a modern, premium, SEO-friendly affiliate product discovery website called **SetupForge**.

## Brand

**Name:** SetupForge
**Tagline:** Build a Better Setup.

SetupForge helps users discover the best products for:

* Home office setups
* Desk setups
* Developer setups
* Productivity accessories
* Tech accessories

Target audience: English-speaking global audience, primarily USA.

---

# Design Requirements

Create a premium, modern technology and workspace brand.

Design style:

* Clean and minimal
* Premium editorial website
* Modern SaaS-style UI
* High-quality typography
* Plenty of whitespace
* Professional and trustworthy
* Fully responsive for mobile, tablet, and desktop
* Fast and SEO-friendly layout

Use a subtle dark/white modern design with a strong accent color.

Do not make the website look like a generic Amazon affiliate website.

The website should feel like a professional product discovery platform.

# Technical Requirements

Use:

* React
* TypeScript
* Tailwind CSS
* Responsive design

Create clean reusable components.

Use realistic placeholder content and high-quality images.

Structure the code so a backend, CMS, Supabase database, Amazon affiliate links, AI content generation system, and Pinterest automation can easily be integrated later.

Do NOT build login, payments, or admin dashboards yet.

Focus on creating a beautiful, fast, production-quality public website UI.

Ensure proper SEO-friendly HTML structure and metadata placeholders.

Use a consistent design system across all pages.

The final result should feel similar in quality to a modern premium product discovery and editorial website, not a basic template.
